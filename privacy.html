Privacy Policy

Shorts Autopilot · Last updated: 16 November 2026

Shorts Autopilot ("the app") is a personal tool operated by Paolo Sagliocco for his own YouTube channel. It is not offered to the public.

YouTube API Services

The app uses YouTube API Services. By using the app you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Data the app accesses

  • Public YouTube data (search results, video titles and view statistics) to identify popular topics.
  • The owner's YouTube account, through Google OAuth with the youtube.upload permission, only to upload videos the owner has approved.

How data is used and stored

  • The OAuth access and refresh tokens are stored only on the owner's private server and are used only to upload approved videos.
  • Public YouTube data is used only to compute topic statistics and is not sold, shared or used for advertising.
  • No data from any other user is collected, because the app has no other users.

Sharing

The app does not share data with third parties, except the services strictly needed to produce videos (stock footage search, text and voice generation), which receive only the video topic and script, never account data.

Revoking access

Access can be revoked at any time from the Google security settings page. Revoking access stops all uploads; the stored tokens are then deleted.
